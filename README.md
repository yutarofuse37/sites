# sites

[布施 祐大郎（Yutaro Fuse）](https://sites.google.com/view/yutaro-fuse/home) の個人ホームページです。

Google Sites の内容（自己紹介・学歴・経歴・Papers/Talks・Slides）をもとに再構成しています。

## 構成

- `index.html` — ページ本体
- `styles.css` — スタイル
- `main.js` — スクロール演出・ヘッダー切替
- `favicon.svg` — ファビコン

## ローカルで確認

```bash
python3 -m http.server 8080
```

ブラウザで http://localhost:8080 を開いてください。
