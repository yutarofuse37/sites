GitHub トークンでログイン

GitHub の「Sign in with GitHub」ボタンは別サーバーが必要なため使えません。 代わりに Personal Access Token を使います（1回作ればOK）。

  1. Fine-grained token 作成ページ を開く
  2. Token name に例: sites-editor
  3. Repository access で yutarofuse37/sites だけを選択
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token して、表示されたトークンを下に貼る
